日本語で話しかけるだけで、画像・動画生成AI用のプロンプトを作るツールです。

これは PromptStudio の説明書です（購入前に全文を公開しています）

ご購入後に同梱されるものと、同じ内容です。お使いのパソコンで動くか、ご自身の用途に合う道具かを、買う前に確かめてください。

動作環境：Windows 10 / 11 ／ NVIDIA製グラフィックボード・VRAM 12GB以上 ／ 空き容量 10GB程度

1. このツールは何をするもの？

画像や動画の生成AIには、「プロンプト」という指示文を英語で書いて渡す必要があります。

ところがこのプロンプトには独特の作法があり、しかも使うモデルによって書き方がまったく違います。同じ言葉を書いても、あるモデルでは効き、別のモデルでは何の意味も持たない、ということが普通に起こります。

PromptStudio は、日本語で「こういう絵が作りたい」と話しかけるだけで、そのモデルに合った英語のプロンプトを組み立ててくれるツールです。

たとえば、こう使います

あなた:「夕暮れの教室で、女の子が窓際からこちらを振り向く」

AI:「髪の色と服装のイメージを教えてください」と質問しつつ、右側にプロンプトを表示

あなた:「黒髪ロング、制服で」

→ 完成したプロンプトをコピーして、お使いの生成AIに貼り付けるだけです。

このツールがやらないこと

  • 画像や動画そのものを作ることはできません（作るのは文章だけです）
  • 生成AIのモデルを配ったり、インストールしたりはしません
  • ComfyUI などの生成環境の準備・設定には関わりません

出来上がったプロンプトを、どの環境でどう使うかは、あなたご自身で行っていただく形になります。

2. 動かすのに必要なもの

必要なもの説明
Windows パソコンWindows 10 または 11
グラフィックボードNVIDIA製・VRAM 12GB以上（下の囲みを参照）
Python本体に同梱されています。別途の準備は不要です
OllamaAIを動かすための土台となる無料ソフトです
AIモデル約6.6GB。プロンプトを書いてくれるAIの本体です
空き容量10GB程度（27bも使う場合は25GB程度）
グラフィックボードは VRAM 12GB以上が必要です

AIモデルは、グラフィックボードのメモリ（VRAM）に丸ごと載せて動かします。載りきらないと、Windows があふれた分をメインメモリへ逃がすため、エラーは出ないまま十倍以上遅くなります。

VRAM使えるモデル快適さ
24GB以上9b ＋ 27b q3_Kすべて使えます
16GB9b快適です
12GB9bこれが下限です
8GB以下—非対応

8GB以下のカードや、グラフィックボードのないパソコンは対象外です。より小さいモデルも試しましたが、本ツールがAIへ渡す指示文が長いため、プロンプトを出さずに質問だけして止まってしまいます。「動くけれど使えない」状態になるため、対応外とさせていただいています。

すでに画像生成をされている方であれば、十分な性能をお持ちのはずです。

用意しているモデルは2つです
モデル大きさ用途
9b約 6.6GB普段はこちら。画像用のプロンプトは数十秒で返ってきます
27b q3_K約 14GBMiniMax H3 を作るとき。賢いぶん遅くなります

この2つは、実際に動かして品質を確認したうえで選んでいます。動作を保証するのはこの2つだけです。

他のモデルを追加してお使いいただくこともできます。上部の「チャットモデル」に自動で並びますので、切り替えるだけです。ただしその場合の動作・品質は保証いたしかねます。詳しくは「13. よくある質問」をご覧ください。

3. 最初の準備

インストーラーからお使いいただいた場合、この章の作業はすべて完了しています。次の章へお進みください。

手動で用意する場合、または不足しているものがある場合は、以下の手順で準備してください。

1

Ollama をインストールする

ollama.com/download から Windows 版をダウンロードして実行します。インストール後は画面右下（時計の近く）に常駐します。

2

モデルの保存先を決める（任意）

そのままだと C ドライブに保存されます。別の場所にしたい場合は、Windows の検索で「環境変数」を開き、ユーザー環境変数に次を追加してください。

変数名  : OLLAMA_MODELS
変数値  : D:\Ollama\models   ← お好きな場所を指定

設定したら、パソコンを再起動してください。

3

モデルをダウンロードする

Windows キー + X を押し、「ターミナル」を選びます。開いた画面に次を貼り付けて Enter を押してください。

ollama pull huihui_ai/qwen3.5-abliterated:9b

約6.6GB のダウンロードが始まります。回線にもよりますが10分ほどかかります。まずはこれだけで使い始められます。

VRAM が 24GB 以上ある場合は、MiniMax H3 用にもう1つ入れておくと便利です（約14GB）。

ollama pull huihui_ai/Qwen3.8-abliterated:27b-q3_K

用意しているのはこの2つです。それ以外のモデルについては「13. よくある質問」をご覧ください。

4. 起動と終了

起動する

PromptStudio をダブルクリックしてください。数秒後、ブラウザが自動で開きます。

黒い画面などは表示されません。何も起きないように見えても、3〜4秒お待ちください。

終了する

画面右上の「終了」ボタンを押してください。確認のあと停止します。タブを閉じるだけでは、裏で動き続けます。

「終了」を押さずに閉じてしまったら

害はありませんが、次に起動したときに動作がおかしくなることがあります。その場合は _system フォルダの中にある stop.bat をダブルクリックすると確実に停止できます。

スタートメニューの「PromptStudio を停止する」からでも同じことができます。

フォルダの中身

インストール先を開くと、次のようになっています。普段さわるのは上の3つだけです。

名前中身
PromptStudio起動します。デスクトップのショートカットと同じものです
使い方.htmlこの説明書です。ツールが起動しなくても開けます
README.txtご利用上の注意。ツール内の「情報」ボタンでも同じものが読めます
dataあなたのデータ。会話・保存プロンプト・常に追加するタグ
profiles対応している生成AIの定義。上級者向け（13章参照）
_system内部ファイルです。さわる必要はありません
引っ越し・バックアップ

data フォルダさえコピーしておけば、会話も保存プロンプトも設定も丸ごと残ります。新しいパソコンに入れ直したときは、インストール後にこのフォルダを上書きしてください。

5. 画面の見方

画面は大きく3つに分かれています。

場所役割
上部の帯どのモデル向けに作るか、どんな絵にするかを選びます
左側日本語でAIと会話するところ
右側完成したプロンプトが表示されるところ

右側の使い方

  • コピー … その欄の内容をコピーします。生成AIの入力欄に貼り付けてください
  • 和訳 … 英語の内容を日本語で確認できます。もう一度押すと英語に戻ります。和訳のままでも、札の「×」で語を消せます
  • 除外 N … あなたが消した語の数です。押すと一覧が出て、1つずつ／まとめて元に戻せます
  • 直接編集 … 欄をクリックすれば、その場で書き換えられます
  • 語数の表示 … 見出しの横に出ます。タグの数の目安になります
手で直した内容は守られます

あなたが手で書き換えた部分を、AIが勝手に元に戻すことはありません。「そこは変えないで」と言わなくても大丈夫です。

6. はじめての1本を作る

1

上部の「プロファイル」で、お使いのモデルの種類を選びます

どれを選べばよいかは 7章 をご覧ください。分からなければ、まずは一番上のままで構いません。

2

左下の入力欄に、日本語で作りたいものを書きます

夕暮れの教室で、女の子が窓際からこちらを振り向く

Enter で送信、Shift+Enter で改行です。

3

AIが質問してきたら、答えます

「髪の色は？」「服装は？」といった質問が返ってきます。答えるほど狙いに近づきます。

質問に答えたくないときは、無視して次の指示を出しても構いません。

4

気になるところを、そのまま日本語で伝えます

もっと夕日を強く
髪を銀色に
背景をぼかして

会話を重ねるほど精度が上がります。一度で完成させようとしなくて構いません。

5

「コピー」を押して、お使いの生成AIに貼り付けます

プロンプトとネガティブプロンプトは別々の欄です。それぞれの欄に貼り付けてください。

7. プロファイルの選び方（重要）

ここを間違えると、まったく効かないプロンプトができてしまいます。お使いのモデルに合わせて選んでください。

プロファイルこんなモデルを使っているなら
Illustrious / NoobAI 系 Illustrious XL、NoobAI-XL、WAI-illustrious、Animagine、およびそれらを元にしたモデル。アニメ系で最も広く使われている系統です
Pony Diffusion V6 XL 系 Pony Diffusion V6 XL と、その派生モデル
FLUX / Qwen-Image 系 FLUX.1、FLUX.2、Qwen-Image、SD3.5、Chroma
WAN / LTX / Hunyuan 系 動画生成。WAN 2.2、LTX-2、HunyuanVideo
MiniMax H3 動画生成。MiniMax H3
なぜ選び分けが必要なのか

たとえば Pony 系では score_9 という語を先頭に置かないと画質が出ません。しかし同じ語を Illustrious 系に渡してもまったくの無意味です。

逆に Illustrious 系で使う masterpiece は、Pony 系では効果がありません。

見た目がよく似ているのに互換性がないため、間違えたまま使い続けている方が非常に多い部分です。プロファイルを選ぶだけで、この違いを自動で吸収します。

お使いのモデルが分からないときは

モデルをダウンロードしたページに、「ベースモデル」という表記があります。そこに Illustrious や Pony と書かれているはずです。

8. 上部の設定項目

設定項目は、選んだプロファイルによって変わります。各項目にマウスを乗せると説明が出ます。

項目内容
プロファイルお使いの生成AIの種類。7章参照
生成モデル同じ系統の中での細かい種別。ネガティブの扱いなどが変わります
モード文章だけで作るか、画像を使うか
画風アニメか実写か。細かい度合いは会話でAIに伝えます
画角全身、膝上、上半身、顔アップなど
露出度健全／ヌードの2つ。どこまで描くかは会話で決まります
推論「使う」は丁寧で高品質、数十秒。「使わない」は数秒だが返答が短い
対話「じっくり相談」はAIが質問してくる。「すぐ出す」は質問せず即完成
チャットモデルプロンプトを書くAI本体。数字が大きいほど賢く、遅い。MiniMax H3 のときは 27b q3_K をおすすめします（下の囲みを参照）
VRAMを解放チャットAIをVRAMから降ろします。動画生成の前に押してください（下の囲みを参照）
動画生成と同時に使うときは「VRAMを解放」を押してください

チャットAIはグラフィックボードのメモリ（VRAM）を使います。しかも、返答が終わってもすぐには降りません。次の質問にすぐ答えられるよう、5分間そのまま居座ります。「会話していないから空いているはず」とはなりません。

チャットモデル占有するVRAM
9b約 6〜7 GB
27b q3_K約 17 GB

画像生成と並行する程度なら問題になりにくいのですが、動画生成はVRAMを大量に使います。チャットAIが居座ったままだと、動画側に回るVRAMが足りなくなり、極端に遅くなったり生成に失敗したりします。

チャットモデルの右にある「VRAMを解放」ボタンを押してください。数秒でVRAMが返ってきます。

解放しても設定や会話は消えません。次にメッセージを送れば自動で読み込み直されます（そのときだけ数十秒かかります）。

押し忘れても、5分経てば自動で解放されます。ただし動画生成を始める前に押しておくのが確実です。

いま何が読み込まれているかは、ターミナルで ollama ps と打つと確認できます。

なお、「終了」ボタンを押したときと、ブラウザのタブや窓を閉じたときは、ボタンを押さなくても自動でVRAMが解放されます（閉じてから約8秒後）。ページを再読み込みしただけの場合は解放されないので、読み込み直しの待ち時間は発生しません。

MiniMax H3 を作るときは 27b q3_K をおすすめします

H3 のプロンプトは、時刻・話者ID・セリフ記法・音の指定が入り組んだ、かなり複雑な形式です。9b では、指定したセリフが抜け落ちることがあります。

同じ「もう行かなきゃ」という指定に対して
  9b     … 「唇が言葉を形づくる」で終わり、セリフ記法なし → 声が出ない
  27b q3_K … <d>[Japanese] もう行かなきゃ</d> を正しく出力

27b q3_K は返答までの時間が9b の数倍かかりますが、H3 は動画の生成自体に数分かかる作業なので、ここで待つ価値があります。

画像を数多く作るときは 9b のままで十分です。そちらは速さが効いてきます。

27b が「返ってこない」ときは、VRAMがあふれています

27b q3_K は動かすのに約 17GBを使います。ブラウザや他のアプリもVRAMを使っているので、24GB のカードでもぎりぎりです。

あふれたぶんは、Windows が黙ってメインメモリへ逃がします。エラーは出ません。ただ、とてつもなく遅くなります。実測では、同じ一言の返事が 39秒 → 624秒（約16倍）になりました。

ツール側では、お使いのグラフィックボードの空き具合を見て、AIが一度に読める文章の量を自動で調整しています。VRAMに余裕がないパソコンでは自動的に控えめな設定になるため、この設定を意識していただく必要はありません。それでも返ってこないときは、次を試してください。

  • ブラウザの他のタブ、画像・動画生成ツール、ゲームなどを閉じる
  • 「VRAMを解放」を押してから、あらためて送信する
  • それでも重いなら 9b に戻す

いまVRAMがどれだけ空いているかは、ターミナルで nvidia-smi と打つと確認できます。

「推論」と「対話」の使い分け

じっくり作りたいとき … 推論「使う」＋対話「じっくり相談」

数をこなしたいとき … 推論「使わない」＋対話「すぐ出す」（数秒で返ってきます）

設定を変えたときは、次に何か送信したときから反映されます。「10秒に伸ばして」などと一言送れば作り直してくれます。

9. 画像を使う

画像を添付する

方法は3通りあります。どれでも構いません。

  • 「画像」ボタンを押してファイルを選ぶ
  • 左側のエリアにドラッグ＆ドロップする
  • 入力欄で Ctrl+V を押して貼り付ける

添付すると小さな画像が並び、左上に ①②③ と番号が付きます。この番号が、動画生成での「1枚目・2枚目」に対応します。最大4枚までです。

参照画像から作る

モードを「参照画像から生成」に変えて画像を添付すると、AIがその画像を実際に見て、写っているものをプロンプトに変換します。「この雰囲気で、髪だけ銀色に」といった使い方ができます。

画像から既存のプロンプトを読み取る

ComfyUI や A1111、NovelAI で作った画像には、生成時のプロンプトが埋め込まれています。そうした画像を添付すると、AIを通さずに、埋め込まれていた内容がそのまま右側の欄に出ます。

「scene_01.png」に埋め込まれていた A1111系 のプロンプトです。変えたいところを日本語で伝えてください。
シード値: 3141592653
  • プロンプトとネガティブプロンプトの両方が、それぞれの欄に入ります
  • シード値も記録されていれば別の行に表示します。同じ絵柄を再現したいときにお使いください
  • AIは何も考えません。読み取ったものが、読み取ったまま出ます（待ち時間もありません）

そのあと 「これの髪を銀色にして」 と話しかければ、この内容を土台にAIが直してくれます。

読み取れた画像には緑の「P」マークが付き、マウスを乗せると内容を確認できます。

ComfyUI の画像について

ComfyUI の画像では、ワークフローをたどってどちらがプロンプトでどちらがネガティブかを判別しています。特殊な組み方で判別できなかった場合は、読み取れた文章をまとめてプロンプト欄に入れ、その旨をお知らせします。

画像を2枚以上まとめて添付した場合、欄に出るのは1枚目だけです。2枚目以降の内容は、会話の中でAIに渡されます。

読み取れない場合もあります

画像を加工したり、SNS に上げたものを保存し直したりすると、埋め込み情報は消えてしまいます。その場合は通常どおり、AIが画像を見て判断します。

10. 便利な機能

和訳 — 英語が読めなくても確認できる

出力欄の「和訳」ボタンを押すと、英語の内容が日本語で表示されます。

masterpiece ＝ 傑作
cowboy shot ＝ 腰から上の構図
depth of field ＝ 奥行きのぼかし

「なぜこの語が入っているのか」が分かります。もう一度押すと英語に戻ります。和訳を表示していても、コピーされるのは英語の原文ですのでご安心ください。

タグ形式の欄では、和訳は1語ずつの札で表示されます。それぞれの札の「×」を押せば、和訳を見たままその語を消せます。英語に戻す必要はありません。

消した語は、二度と戻ってきません

あなたが手で消した語は、ツールが覚えていて、AIが次にまた書いてきても自動で取り除きます。

消した語がある欄には、見出しに「除外 3」のような赤いボタンが出ます。押すと、消した語が一覧で並びます。

  • 各語の「×」 … その語だけを除外から外します
  • 「全部もどす」 … その欄の除外をまとめて解除します

「やっぱりあの語だけ必要だった」というときは、×で1つずつ戻してください。

プロンプトが長くなりすぎるのを防いでいます

会話を重ねると、AIは前に書いた語をどんどん足していきがちです。語が増えるほど1語ずつの効き目は弱まるので、後から出した指示ほど通らなくなります。

本ツールでは、AIに渡す過去の会話から古いプロンプトを取り除き、最新の1つだけを見せています。さらにAIには「プロンプトは毎回書き直すものであって、積み上げるものではない」と指示してあります。

それでも語が増えすぎたと感じたら、いらない語を手で消してください。一度消せば、もう戻ってきません。

保存プロンプト — 作品名・キャラ名・衣装を引き出しにしまう

上部の「定型」ボタンを押し、「保存プロンプト」タブを開きます。ここは、よく使うタグをフォルダで整理してしまっておく引き出しです。

▾ 原神
   ▾ ニィロウ
      ・通常衣装   nilou \(genshin impact\), blue hair, veil ...
      ・水着       nilou \(genshin impact\), bikini, wet ...
   ▾ 胡桃
▾ お気に入りの構図
   ・逆光の夕暮れ   backlighting, sunset, lens flare ...

フォルダは何段でも作れます。作品名 → キャラ名 → 衣装、という並べ方でも、「お気に入りの構図」のように自分用のまとめ方でも構いません。LoRA のトリガー語をキャラごとにしまっておく使い方が便利です。

作り方

  • ＋ フォルダを作る … いちばん外側にフォルダを作ります
  • ＋ フォルダ（各行） … そのフォルダの中に、さらにフォルダを作ります
  • ＋ 区分け（各行） … そのフォルダの中に、区分け（衣装名・場面名など）を作ります。名前を付けると中身を書く画面が開くので、そこにタグを入れてください

使い方

  • 入れる … その区分けのタグを、今のプロンプトに差し込みます。品質タグの直後（いちばん効く位置）に入り、AIが勝手に消すことはありません。すでに同じ語があれば重複しません
  • 編集 … 中身と、どの欄（プロンプト／ネガティブ）に入れるかを変えられます
  • 名前 / ↑ / × … 名前の変更、ひとつ上へ移動、削除です
  • フォルダ名の左の ▾ … 折りたたみます。数が増えてきたら使ってください

登録した内容は data\library.json に保存されます。会話とは別に残るので、「新規」で会話を始め直しても消えません。

ここから入れたタグは、AIが消しません

「入れる」で差し込んだタグは固定されます。会話を続けてAIがプロンプトを書き直しても、毎回かならず同じ位置（品質タグの直後）に残ります。

いらなくなったら、プロンプト欄から手で消してください。あなたが消したものは固定が外れ、以後は戻ってきません。「AIは消せない、あなただけが消せる」という動きです。

定型 — 毎回入れるタグを登録しておく

上部の「定型」ボタンから、毎回自動で足したい語を登録できます。

  • キャラクターLoRA のトリガー語
  • いつも使う品質タグ
  • 常に外したいネガティブ

登録した語は、効きが強くなるプロンプトの前のほうに自動で差し込まれます。同じ語が重なっても自動でまとめられます。

この設定はプロファイルごとに別々に保存されます。

履歴 — 前の案に戻す

右上の「履歴」ボタンで、その会話で作ってきたプロンプトが一覧できます。

「3回目の案が良かった」というときに、「これに戻す」で呼び戻せます。戻したあと会話を続ければ、その内容が土台になります。

会話の保存 — 案件ごとに分けておく

  • 保存 … 名前を付けて残せます。日本語の名前も使えます
  • 読込 … 保存した会話を呼び出します
  • 新規 … まっさらな状態から始めます

保存しなくても、閉じたときの続きは次回自動で復元されます。

入力欄の大きさを変える

入力欄のすぐ上にある細い横棒を上下にドラッグすると、高さが変わります。長い文章を書くときに広げてください。ダブルクリックで元に戻ります。大きさは記憶されます。

11. よい結果を出すコツ

一度で完成させようとしない

最初から細かく指定するより、ざっくり伝えて、あとから直していくほうがうまくいきます。「もっと」「少なめに」といった曖昧な言い方でも通じます。

キャラクターの名前は伝えてよい

「◯◯というゲームの△△というキャラクターです」と伝えると、そのキャラクター名のタグを入れてくれます。画像を添付しながら伝えると、より正確になります。

ただし似せるには、そのキャラクター用の LoRA が別途必要です。プロンプトだけでは限界があります。

プロンプトの長さには上限があります

生成AIが読み取れる量には、モデルごとに決まった上限があります。そこを超えた分は、書いても読まれません。

プロファイル読み取れる上限ちょうどよい量
Illustrious / NoobAI 系約248トークン（およそ70〜80タグ）25〜45タグ
Pony 系約225〜248トークン（およそ70タグ）25〜45タグ（スコアタグの後ろで）
FLUX / Qwen-Image 系512トークン（およそ350語）。Qwen-Image は約100060〜150語
WAN / LTX / Hunyuan 系320トークン（512まで入るが、320超で画質が落ちるため）30〜80語（開始＋終了画像なら60〜120）
MiniMax H37,000文字150〜450語（このモデルだけ長文が必要）

プロンプト欄の見出しに「12 語 / 約 40 トークン」のように表示されます。

上限を超えた分は、自動で切られます

AIが上限を超える量を書いてきた場合、読み取られない部分を自動で取り除きます。残しても効果がなく、あるように見えてしまうためです。

切ったときは、チャット欄で何を切ったかをお知らせします。黙って消すことはありません。

プロンプトが 248 トークンの上限を超えたため、末尾を切りました
（このモデルはここから先を読み取れません）: extra tag 34, extra tag 35, …
  • 切られるのは末尾からです。前にある大事なタグは残ります
  • 保存プロンプトから入れた固定タグは、品質タグの直後にあるので切られません
  • 文章形式では、文の途中ではなく文の切れ目で切ります
  • MiniMax H3 だけは切りません。3つの欄の構造が壊れると使えなくなるためで、代わりに警告を出します
  • 手入力で超えた場合は切りません。表示がオレンジ色になってお知らせするだけです（打っている途中で消されると困るため）
上限より大事なこと

タグは前にあるものほど強く効き、後ろにいくほど薄まります。上限に達していなくても、長くすればするほど1つあたりの効き目は弱くなります。

ですから「入るだけ詰める」のではなく、本当に必要なものを前に置くのが正解です。逆に、あなたが必要とする指定を遠慮して削る必要はありません。

思ったものが出ないときは、和訳で確かめる

意図と違う絵ができたときは、まず「和訳」で中身を確認してください。「そんなつもりで言っていない語」が入っていることがよくあります。見つけたら、その場で直接消してしまうのが早いです。

画風の設定を活用する

実写にしたいのにアニメ調になってしまう場合、画風を「実写」にしてください。アニメ調を打ち消す語が、ネガティブに自動で追加されます。「もっと写真らしく」といった細かい度合いは、そのまま会話でAIに伝えてください。

12. うまくいかないとき

ダブルクリックしても何も起きない

  • まず4〜5秒お待ちください。すぐには開きません
  • それでも開かない場合、_system フォルダの中にある start.bat をダブルクリックしてください。黒い画面にエラーの内容が表示されます

Ollama のサインイン画面が出た

サインインは不要です。「Local」を選ぶか、そのウィンドウを閉じてください。

Ollama にはアカウントでログインして使う機能もありますが、それはインターネット上のAIを使うためのものです。本ツールはすべてお使いのパソコンの中だけで動くため、アカウントは一切必要ありません。

インストール中にこの画面が出て止まったように見えたら

Ollama を入れた直後に、この画面が出ることがあります。「Local」を選ぶか閉じてから、インストール先の _system フォルダにある setup_model.bat をダブルクリックしてください。AIモデルのダウンロードが始まります。

ダウンロードが終わっているかどうかは、ターミナルで次のように確認できます。

ollama list

huihui_ai/qwen3.5-abliterated:9b が表示されれば完了しています。

「モデルなし」と表示される / AIが返事をしない

Ollama が動いていない可能性が高いです。

  1. 画面右下（時計の近く）に Ollama のアイコンがあるか確認してください
  2. なければ、スタートメニューから Ollama を起動してください
  3. それでも直らない場合は、パソコンを再起動してみてください

画面の表示が古いまま変わらない

Ctrl + F5 を押してください。ブラウザが古い画面を保持していることがあります。

AIの返事が短い / 内容が薄い

上部の「推論」が「使わない」になっていないか確認してください。「使う」にすると、時間はかかりますが返答の質が上がります。

返事が返ってこない

そのまま少しお待ちください。推論を使っている場合、数十秒かかることがあります。27b q3_K は数分かかることもあります。

「AIから応答がありませんでした」と出た場合は、送信した内容が入力欄に戻っていますのでもう一度お送りください。

何分待っても返ってこない場合は、VRAMがあふれている可能性が高いです。画像・動画生成ツールやゲーム、ブラウザの他のタブを閉じてからお試しください。8章の囲みもご覧ください。

用意している2つ以外のモデルをお使いの場合は、まず 9b に戻してお試しください。小さすぎるモデルは、質問だけしてプロンプトを出さないことがあります。

会話がおかしくなった

「新規」を押して作り直すのが最も確実です。長く続けた会話は、AIが混乱することがあります。

13. よくある質問

Q. インターネットに接続していないと使えませんか？

いいえ。すべてお使いのパソコンの中だけで動きます。入力した内容が外部に送られることはありません。最初にモデルをダウンロードするときだけ接続が必要です。

Q. 作ったプロンプトは自由に使えますか？

はい。商用・非商用を問わず自由にお使いいただけます。使用料も、このツールを使ったという表記の義務もありません。

Q. 対応していないモデルのプロンプトは作れませんか？

近い系統のプロファイルを選べば、多くの場合そのまま使えます。プロンプトの書き方は、大きく分けると数種類しかないためです。

Q. 用意されている2つ以外のAIモデルを使えますか？

使えます。ただし動作は保証いたしかねます。

ターミナルで ollama pull したモデルは、上部の「チャットモデル」に自動で並びます。選ぶだけで切り替わり、設定は必要ありません。より新しいモデルが出たときや、お手持ちのモデルを試したいときにお使いください。

ただし、本ツールが動作を確認しているのは 9b と 27b q3_K の2つだけです。他のモデルでうまくいかない場合は、この2つに戻してからお試しください。

選ぶ前に確認していただきたいこと

本ツールは、AIに対して非常に長い指示文（タグの作法・語彙・書式の決まりごと）を渡しています。そのため、次の条件を満たさないモデルでは正しく動きません。

  • 画像を読めること … 参照画像モードで必要です。「vision」対応と書かれているものを選んでください
  • 小さすぎないこと … 4B 以下は、プロンプトを出さずに質問だけして止まります。指示文が長すぎて「必ずプロンプトを出す」という決まりを保持できないためです
  • 制限のかかっていないもの … 通常のモデルは、露出度を「ヌード」にしても拒否することがあります

お使いのモデルが何に対応しているかは、ターミナルで次のように調べられます。

ollama show モデル名

Capabilities の欄に vision と thinking が両方あることをご確認ください。

Q. AIはどこまで知っているのですか？

プロファイルごとに、そのモデル専用の作法を持たせてあります。主なものは次のとおりです。

  • Illustrious / Pony 系 … Danbooruタグの語彙。品質タグ・年代タグ（newest など絵柄そのものが変わるもの）・画風タグ・光・構図・効果・髪や目の描写。絵師タグの使い方と括弧のエスケープも入っています
  • FLUX / Qwen-Image 系 … 主語→動作→画風→状況の順、光源とレンズの書き方、質感語、画像内の文字の指定方法
  • WAN / LTX / Hunyuan 系 … 系統ごとの書き分け、カメラワークの言い方、WAN公式の中国語ネガティブプロンプト、動きの書き方
  • MiniMax H3 … 公式ガイド準拠の記法。カメラの正式語彙（種類＋振幅＋速度）、カット記法、話者ID、<d>タグ、音声2欄の書き分け

収録しているタグは実際に使われている件数を調べて選別しています。よく見かける detailed eyes、cinematic lighting、god rays などは実在しないため何の効果もありません。本ツールはこれらを書かず、実在する語に置き換えます。

Q. NSFW の内容も作れますか？

はい。制限をかけていないAIを使用しています。上部の「露出度」を「ヌード」にしてください。

この設定は「どこまで描くか」を決めるものではありません。性的な表現を出してよいかどうかの、単なる切り替えです。関連する分野の語彙が、まとめて使えるようになります。収録している語の内訳は、商品ページに記載しています。

どこまで描くかは、あなたが会話で伝えた内容だけで決まります。控えめに頼めば控えめに、はっきり指示すればそのとおりに書きます。何も言わなければ、AIは控えめにして質問してきます。表現を止めるのは「健全」のときだけです。

収録している語は、実際に使われている件数を調べたうえで選んでいます。見た目がそれらしくても実在しない語はモデルに何も伝わらないため、そこを外さないようにしてあります。

Q. 動作が遅いのですが

チャットモデルを軽いもの（数字が小さいもの）に変えるか、「推論」を「使わない」にしてください。数秒で返ってくるようになります。

Q. 設定や会話はどこに保存されますか？

すべて data フォルダの中です。

場所中身
data\sessions保存した会話と、前回の続き
data\prefs.json「常に追加するタグ」
data\library.json「保存プロンプト」

バックアップは data フォルダをコピーするだけで十分です。新しい版に入れ替えるときも、このフォルダを残しておけば設定と会話は引き継がれます。

14. ディスク容量について（重要）

「知らないうちにドライブが圧迫されている」という事態を避けるため、何がどこに、どれくらいの大きさで保存されるのかをご説明します。

容量を使うのは AIモデルだけです

対象おおよその大きさ
PromptStudio 本体約 30 MB（ごくわずかです）
会話の履歴数百 KB 程度。何百回会話しても増えません
Ollama 本体約 2.7 GB
AIモデル（9b）約 6.6 GB
AIモデル（27b q3_K）約 14 GB
会話を重ねても容量は増えません

会話の履歴は文字だけなので、非常に小さなものです。画像を添付した場合でも、縮小して保存するため大きくはなりません。

容量を使っているのは、ほぼすべて AIモデルです。そして、モデルは最初に一度ダウンロードするだけで、あとから勝手に増えることはありません。

モデルの保存場所を確認する

モデルは、標準では次の場所に保存されます。

C:\Users\（ユーザー名）\.ollama\models

この場所を変えたい場合は、環境変数 OLLAMA_MODELS に保存したい場所を指定します。

設定するタイミングにご注意ください

Ollama は起動したときにこの設定を読み込みます。そのため、

  • Ollama がすでに起動している状態で設定を変えても反映されません
  • 設定を変えたら、必ず Ollama を終了して起動し直すか、パソコンを再起動してください

これを忘れると、指定した場所ではなく C ドライブに保存されてしまいます。

いま、どこに保存されているか調べる

Windows キー + X →「ターミナル」を開き、次を貼り付けてください。

explorer "$env:USERPROFILE\.ollama\models"

フォルダが開いて中身が入っていれば、C ドライブに保存されています。

保存場所を後から移動する

1

Ollama を完全に終了します

画面右下（時計の近く）の Ollama アイコンを右クリックして「Quit」を選びます。

2

環境変数を設定します

Windows の検索で「環境変数」→ ユーザー環境変数に OLLAMA_MODELS を追加し、移動先のフォルダを指定します。

3

フォルダの中身を移動します

C:\Users\（ユーザー名）\.ollama\models の中身を、指定した場所へすべて移します。

4

パソコンを再起動します

再起動後、ターミナルで ollama list と入力し、モデルが表示されれば成功です。

使わないモデルを削除する

容量を空けたいときは、使っていないモデルを削除できます。

ollama list                                        ← 一覧を表示
ollama rm huihui_ai/Qwen3.8-abliterated:27b-q3_K   ← 削除する

削除しても、必要になれば再びダウンロードできます。MiniMax H3 を使わないのであれば、27b q3_K を消すだけで 14GB 空きます。
